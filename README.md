# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核批注和冻结版本均保存在浏览器本机，可离线编辑。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、危险项、控制措施、安全说明、预期结果和依赖关系。
- 步骤可登记产出物名称与批次，并勾选消耗的上游产出，与依赖关系一起构成流转链路。
- 上游批次、用量或产出名称变化后，消耗该产物的步骤及下游复核自动失效；失效步骤保留原确认和失效原因，重新确认后才能再次冻结。
- 旧草稿打开时自动补流转关系：唯一前置依赖直接接上，无法唯一对应的列为待整理且不沿用旧确认结论；补全处理失败时恢复原流程。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖。
- 修改步骤后自动计算全部下游步骤，提醒受影响的后续步骤和已确认内容。
- 自动识别存在危险项但缺少控制措施或安全说明的步骤，并阻止确认与冻结。
- 提交复核后，复核人可逐条添加批注、标记解决、确认或退回。
- 所有步骤确认、无失效复核、无待整理流转且安全信息完整后才能冻结版本；冻结检查与编辑页读取同一份失效结果。
- 保存多个完整版本快照，比较步骤新增、删除及材料、用量、危险项、依赖、产出批次、消耗关系等字段变化。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 流转逻辑校验

```bash
npm run test:flow
```

对失效传播、旧草稿迁移（唯一对应 / 待整理 / 失败回退）等纯逻辑做断言校验。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。
